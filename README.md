# Árbol de decisión frente a Random Forest — Actividad S10 (Grupo 5)

Simulación interactiva (HTML + JavaScript, Chart.js por CDN) para el curso Agentes Inteligentes, USIL.

- **Pestaña 1 — Gini paso a paso:** 14 correos, Gini por variable y árbol armado nodo por nodo con reglas SI… ENTONCES.
- **Pestaña 2 — Un árbol frente a un bosque:** 200 casos sintéticos con semilla fija para 5 temas; árbol (profundidad 1–10) y Random Forest (1–200 árboles) lado a lado.

**Datos sintéticos con fines didácticos.** No son datos reales de personas ni negocios.
